# 绘 1.0 正式版 · 功能与按键教程

## 对话

左侧新建、搜索和切换聊天，名称可重命名。Enter 发送，Shift+Enter 换行，Alt+N 新建。图片、PDF、DOCX 和文本可拖入页面；图片可粘贴。扫描 PDF 需 OCR 或上传页面图片。

输入区上方手柄可上下拉伸；向下拖到底或点击按钮收起，草稿保留。插入翻译或 Tag 时自动展开。支持停止、重新生成与接着写；自动续写只针对接口明确报告 length 的截断。

设置 → 请求提示词：编辑系统、附加、末尾与续写指令，保存多组方案，查看组合预览。生成参数可调整输出、上下文、温度、续写次数。请求指令不能改变服务商权限、审核或模型能力。

## 翻译

选择中英方向，可实时或手动发送。点击短语对照定位原文和译文，复制结果或发送到 Tag / 对话。标签自动补充翻译不会覆盖翻译工作区内容。

## Tag 编辑

- 输入中文弹出候选，↑↓ 选择、Enter / Tab 选词、Esc 收起、Ctrl+Enter 转换整段。
- 选择正向或负向目标。未匹配中文留待处理；英文词库外标签可保留并自动补充中文，以暖灰色区分。
- 点击标签编辑英文和权重。普通标签小写与空格，保留 score_9，画师用 @ 前缀。权重以实际绘图编码节点支持为准。
- 拖动左侧点状手柄排序，靠近上下边缘自动滚动。手柄上按方向键前后移动，Home / End 移到首尾。
- 标签列表多列显示，右下角可拉高；展开全部可取消内部高度限制。
- 可配置多组正负向前缀，勾选只增减前缀层，不改已有标签、权重与顺序。
- 全部清空删除两侧正文、输入和自然语言补充，取消前缀勾选；保留前缀方案与 API，便于下一张图复用。

## Prompt 预览

Tag 底色对应旁边的颜色图例，不重复显示分类标题。点击图例筛选，再次点击或选择全部恢复；不重排、不删原内容。

中文括注仅供显示，复制不带括注和分类名称，权重保留。复制按钮始终复制完整原文。插入对话同时带明确区分的正负向 Prompt。

## 本地 PixAI 图像辅助

在设置 → 提示词技能中安装 CPU 图像模型并勾选本地 PixAI 图像辅助，上传图片后发送对话。程序会等待本地处理完成，再把图像候选与任务发送给 API。此过程不设等待时限，处理速度取决于电脑性能；需要取消时点击停止生成。

## 配置保存与备份

API 自动保存在本机；配置备份固定包含凭据，可密码加密。导入后恢复 API、翻译、请求方案、Tag 和前缀。聊天另行导出。请使用同一浏览器继续访问，以保留本地历史。

## 打标设备选择与切换

在设置 → 提示词技能中选择本地图像打标设备，再点击安装 / 修复。

- CPU：通用，无需独立显卡；至少保留 3GB 可用内存，速度取决于处理器。
- NVIDIA 显卡：CUDA 加速，通常更快；需要兼容 CUDA 12.8 的 NVIDIA 显卡及 Windows 驱动 570.65 或更高，建议 8GB 及以上显存。Intel / AMD 显卡请选择 CPU。程序自动安装 PyTorch CUDA，无需单独安装 CUDA Toolkit。安装时检查驱动和 CUDA 内核，不支持时显示原因。
- 已安装用户：先点击“卸载打标环境”，再选择另一种设备并安装。旧 CPU 安装会自动识别。卸载删除对应图像环境、模型和下载缓存，仅保留 T5 校验及设置。已卸载的模型需重新下载。CPU 与显卡版使用不同权重，各约 1.9GB，显卡依赖还需数 GB 空间。
- 图像辅助不限制等待时间，可随时点击停止生成。显卡版按硬件自动选择 BF16 或 FP32；显存不足需关闭其他占用显存的软件，或卸载后改用 CPU。

运行环境依据：[PyTorch 2.8 安装方案](https://pytorch.org/get-started/previous-versions/)、[CUDA 12.8 Windows 驱动说明](https://docs.nvidia.com/cuda/archive/12.8.0/cuda-toolkit-release-notes/index.html)。
