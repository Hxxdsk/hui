# 功能与按键教程

## 对话

左侧新建、搜索和切换聊天，名称可重命名。Enter 发送，Shift+Enter 换行，Alt+N 新建。图片、PDF、DOCX 和文本可拖入页面；图片可粘贴。扫描 PDF 需 OCR 或上传页面图片。

输入区上方手柄可上下拉伸；向下拖到底或点击按钮收起，草稿保留。插入翻译或 Tag 时自动展开。支持停止、重新生成与接着写；自动续写只针对接口明确报告 length 的截断。

设置 → 请求提示词：编辑系统、附加、末尾与续写指令，保存多组方案，查看组合预览。生成参数可调整输出、上下文、温度、续写次数。请求指令不能改变服务商权限、审核或模型能力。

## 翻译

选择中英方向，可实时或手动发送。点击短语对照定位原文和译文，复制结果或发送到 Tag / 对话。标签自动补充翻译不会覆盖翻译工作区内容。

## Tag 编辑

- 输入中文弹出候选，↑↓ 选择、Enter / Tab 选词、Esc 收起、Ctrl+Enter 转换整段。
- 选择正向或负向目标。未匹配中文留待处理；英文词库外标签可保留并自动补充中文，以暖灰色区分。
- 点击标签编辑英文和权重。普通标签小写与空格，保留 score_9，画师用 @ 前缀。权重以实际绘图编码节点支持为准。
- 拖动左侧点状手柄排序，靠近上下边缘自动滚动。手柄上按方向键前后移动，Home / End 移到首尾。
- 标签列表多列显示，右下角可拉高；展开全部可取消内部高度限制。
- 可配置多组正负向前缀，勾选只增减前缀层，不改已有标签、权重与顺序。
- 全部清空删除两侧正文、输入和自然语言补充，取消前缀勾选；保留前缀方案与 API，便于下一张图复用。

## Prompt 预览

Tag 底色对应旁边的颜色图例，不重复显示分类标题。点击图例筛选，再次点击或选择全部恢复；不重排、不删原内容。

中文括注仅供显示，复制不带括注和分类名称，权重保留。复制按钮始终复制完整原文。插入对话同时带明确区分的正负向 Prompt。

## 备份与升级

API 自动保存本机；配置备份固定包含凭据，可设置密码加密。导入后恢复 API、翻译、请求方案、Tag 与前缀。聊天另行导出。

设置 → 版本更新检查 GitHub 正式发布。右上角新版本提醒可关闭；设置中随时可重新检查。点击后先看版本说明，关闭弹窗不会下载。确认更新后自动下载并重启，无需单独安装更新包，保留原地址、对话和配置。详见 [升级与回滚](UPDATING.md)。
