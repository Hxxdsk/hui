点击更新后先显示版本说明，可随时取消。确认后自动下载并校验，完成更新后回到当前页面，不必手动下载安装包。

使用教程
  1. 设置 → API 连接：填写服务商地址与 Key，检测模型并保存。
  2. 请求提示词：选择方案或自填指令，按需开启末尾约束；生成参数中设置回复上限与自动续写。
  3. 翻译：选择中英方向，开启实时翻译或手动发送；点击短语对照定位，复制或发送到 Tag / 对话。
  4. Tag：输入中文选候选词，Ctrl Enter 转换整段。点击标签编辑权重；拖动左侧手柄，或在手柄上按 ↑↓ / Home / End 排序。列表可拉高或展开全部；全部清空会清除正负向内容并取消前缀勾选。颜色图例可筛选预览。
  5. 图片、PDF、DOCX、文本可拖入页面任意位置；附件加入对话待发送区。Enter 发送，Shift Enter 换行，Alt N 新建对话。输入框上方手柄可上下拉伸，向下拖到底或点击按钮收起，草稿仍保留。
  6. 备份与恢复：可携带 API 凭据，设置密码后加密。API 自动保存在本机，备份导入后可直接恢复使用。
  7. 双击绘.exe 直接进入网页；关闭最后一个网页自动结束服务并释放端口。右上角可关闭更新提示，也可在设置 → 版本更新查看说明，确认后自动更新并重启。
