绘 · hui 1.0 正式版

1. 完整解压，双击绘.exe 直接打开网页。无需安装全局 Node 或 Python。
2. 设置 → API 连接：填写自己的第三方地址、Key 和模型。API 自动保存，其他设置点击保存。
3. 关闭最后一个绘网页后自动结束服务并释放端口。刷新、切换后台或同时打开多个页面不会误退出。
4. 对话 Enter 发送，Shift Enter 换行，Alt N 新建。输入区手柄可拉伸或向下收起，草稿保留；历史可搜索和重命名。
5. 图片、PDF、DOCX 和文本可拖入页面，图片也可粘贴。扫描 PDF 需 OCR 或上传页面图片；图像理解需要视觉模型。
6. 翻译支持中英互译、短语定位，可复制或发送到 Tag / 对话。火山原生 AK/SK 和 DeepL 不需模型网址。
7. 中文 Tag 悬浮候选：上下键选择，Enter / Tab 加入，Esc 收起，Ctrl Enter 转换整段。点击标签编辑英文与权重。
8. 拖动左侧手柄，根据插入线放置标签；靠近上下边缘自动滚动，Esc 取消。手柄支持方向键、Home / End。列表可拉高或展开全部。
9. 正负向 Prompt 底色对应颜色图例，点击临时筛选但不改变原顺序。中文括注仅显示，复制保留英文和权重；插入对话同时区分正负向。
10. 前缀支持多组独立勾选，只增减前缀层。全部清空清除两侧内容、输入和自然语言，取消前缀勾选，保留方案。
11. 提示词技能可启用 anima-tagger，使用创作、扩写、反推与 T5 校验。PixAI CPU 图像模型约 1.9GB，支持代理、续传与校验复用。
12. PixAI 图像辅助不设等待时限，处理完成后继续发送；需要中断时点击停止生成。
13. 备份固定包含 API 凭据、翻译、指令、Tag 与前缀，可密码加密；聊天单独导出。
