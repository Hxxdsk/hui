绘 · Windows x64 便携版

1. 完整解压，双击绘.exe 直接打开网页，不需要启动页或全局 Node / Python。
2. 设置 → API 连接：输入自己的第三方网址、Key 和模型。API 自动保存，其他选项点击保存。
3. 关闭最后一个绘网页，后台自动退出并释放端口。刷新、切换后台或同时打开多个页面不会误退出。
4. 对话、翻译、Tag 在左侧分别进入。Enter 发送，Shift Enter 换行，Alt N 新建。输入区手柄可拉伸，向下拖到底或点按钮收起，草稿保留。
5. 图片、PDF、DOCX 和文本可拖入页面；扫描 PDF 需 OCR 或上传图片，图片需要视觉模型。
6. 翻译支持中英互译、短语定位，结果可复制或发送到 Tag / 对话。火山原生 AK/SK 和 DeepL 不需模型网址。
7. 中文 Tag 悬浮候选：上下键选词、Enter / Tab 加入、Esc 收起、Ctrl Enter 转换整段。点击编辑，手柄拖动排序并自动滚动，方向键 / Home / End 也可排序；列表可拉高或展开全部。
8. 正负向预览用底色与颜色图例区分类别，点击临时筛选但不改变顺序和复制内容。中文括注不参与复制。插入对话同时带正负向。
9. 前缀支持多组独立勾选。全部清空清除两侧 Tag、输入和自然语言补充，取消前缀勾选，保留前缀方案。
10. 备份固定包含 API 凭据、翻译、请求指令、Tag 与前缀，可密码加密；聊天单独导出。
11. 提示词技能可启用 anima-tagger，创作 / 扩写 / 反推与 T5 校验；约 1.9GB CPU 图像模型按需安装、代理、续传、校验复用，升级不重下。本地辅助最多等 8 秒，之后由视觉 API 分析。
12. 有新版本时右上角提示可关闭，设置 → 版本更新随时可进入。先看更新说明，关闭不下载；确认更新后自动下载、校验并重启，无需另下更新包。对话、设置、Tag、草稿和模型保留。
13. 更新失败保留旧版或回滚并重启。无网页更新功能的 2.2–2.4 旧版可用传统升级包迁移一次，之后从网页升级。
